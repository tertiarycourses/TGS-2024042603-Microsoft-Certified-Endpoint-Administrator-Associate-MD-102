## Learning outcomes

- Administer core endpoint security programs and analyze system-update impacts on Microsoft Endpoint administration.
- Perform Microsoft Endpoint system administration and configure authentication to protect against security threats.
- Troubleshoot Microsoft Endpoint security issues and assist users in defining access rights.
- Coordinate advanced access-control rights and investigate unauthorized-access incidents on Microsoft Endpoint systems.

## Current MD-102 coverage

- Prepare infrastructure for devices — 20–25%
- Manage and maintain devices — 25–30%
- Protect devices — 15–20%
- Manage applications — 15–20%
- Optimize endpoint operations — 10–15%

# TGS-2024042603 - Microsoft Certified Endpoint Administrator Associate (MD-102)

> Course: Microsoft Certified Endpoint Administrator Associate (MD-102)  
> Course Code: TGS-2024042603  
> Register here: https://www.tertiarycourses.com.sg/wsq-microsoft-certified-endpoint-administrator-associate-md-102.html

Hands-on Microsoft Endpoint Administrator labs for learners preparing to manage endpoints with Microsoft Intune, Microsoft Entra ID, Windows Autopilot, Windows 365, Microsoft Defender for Endpoint, Microsoft Graph, PowerShell, and automation/reporting workflows. The labs cover device join and enrollment, compliance, Conditional Access, Autopilot, configuration profiles, Intune Suite capabilities, endpoint security, updates, app deployment, app protection, remote actions, endpoint analytics, proactive remediations, and course review.

## How to Use These Labs

1. Read the learner guide before starting the first lab.
2. Complete the labs in order because later exercises reuse earlier Intune, Entra ID, and endpoint concepts.
3. Use a Microsoft 365 Developer tenant, instructor-provided tenant, or approved lab tenant.
4. Do not run remote actions such as wipe or retire on production devices.
5. Clean up test policies, groups, apps, and scripts after class.

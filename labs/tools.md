# Tools Guide

## Required Tools

| Tool | Purpose |
| --- | --- |
| Microsoft Intune admin center | Endpoint enrollment, policy, app, update, security, and reporting management. |
| Microsoft Entra admin center | Device identity, users, groups, Conditional Access, roles. |
| Microsoft 365 admin center | Tenant and service health review. |
| Microsoft Defender portal | Defender for Endpoint and device threat review. |
| PowerShell | Automation and reporting examples. |
| Microsoft Graph Explorer | Explore Graph API concepts safely. |

## Optional Tools

## Cleanup Checklist

At the end of class, check for:

- Lab-only users and groups.
- Test enrollment profiles.
- Test compliance and configuration policies.
- Test security baselines and endpoint security policies.
- Test app deployments and app protection policies.
- Proactive remediation scripts.
- Alert rules or workbooks created only for training.

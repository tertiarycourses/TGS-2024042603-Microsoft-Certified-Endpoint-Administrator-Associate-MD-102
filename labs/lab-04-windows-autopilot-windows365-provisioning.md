# Lab 04 - Windows Autopilot, Windows 365, Provisioning

## Objectives

- Compare Autopilot profiles and device preparation policies.
- Choose Autopilot deployment modes.
- Plan Enrollment Status Page.
- Plan Windows 11 upgrades.
- Plan Windows 365 Cloud PC provisioning.

## Scenario

The company wants new Windows devices shipped directly to users and Cloud PCs provisioned for temporary staff.

## Steps

### 1. Compare Autopilot Modes

| Mode | Use Case |
| --- | --- |
| User-driven | Primary user receives device |
| Pre-provisioning | IT or partner prepares device before handoff |
| Self-deploying | Shared or kiosk-style device |

### 2. Plan an Autopilot Profile

Document:

```text
Profile name
Deployment mode
Join type
Device name template
User account type
Enrollment Status Page settings
Assigned group
```

### 3. Plan Enrollment Status Page

Record:

- Block device use until required apps install.
- Timeout.
- Error behavior.
- Required apps.
- Troubleshooting steps.

### 4. Plan Windows 11 Upgrade

Document:

- Feature update policy.
- Readiness rings.
- Pilot group.
- Rollback considerations.
- Reporting.

### 5. Plan Windows 365 Cloud PCs

Record:

```text
Provisioning policy
Network connection
Image
License assignment
User group
Monitoring and troubleshooting
```

## Validation

You should have Autopilot comparison, profile plan, ESP plan, Windows 11 upgrade plan, and Windows 365 provisioning plan.

## Checkpoint Questions

1. When would you use pre-provisioning?
2. What is a device name template?
3. What does ESP control?
4. What is needed to provision a Cloud PC?

## Exam Focus

Know Autopilot modes, ESP, Windows 11 upgrade planning, and Windows 365 provisioning concepts.

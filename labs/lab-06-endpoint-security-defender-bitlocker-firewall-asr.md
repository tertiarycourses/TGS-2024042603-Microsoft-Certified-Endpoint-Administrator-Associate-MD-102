# Lab 06 - Endpoint Security, Defender, BitLocker, Firewall, ASR

## Objectives

- Plan endpoint security policies in Intune.
- Configure antivirus, disk encryption, firewall, and ASR concepts.
- Plan security baselines.
- Integrate with Microsoft Defender for Endpoint.
- Review App Control for Business.

## Scenario

The security team requires a baseline endpoint protection policy for Windows devices and visibility into endpoint threats.

## Steps

### 1. Design Security Policies

| Control | Policy Area |
| --- | --- |
| Antivirus settings | Endpoint security antivirus |
| BitLocker encryption | Disk encryption |
| Firewall rules | Firewall |
| Attack surface reduction | ASR policy |
| Security baseline | Baselines |
| EDR onboarding | Defender for Endpoint |

### 2. Plan BitLocker

Document:

- Encryption method.
- Silent enablement.
- Recovery key escrow.
- User self-service recovery.
- Compliance reporting.

### 3. Plan ASR Rules

Record:

- Pilot mode.
- Audit mode.
- Block mode.
- Exclusions.
- Reporting.

### 4. Defender for Endpoint Integration

Document:

```text
Tenant connection
Device onboarding
EDR policy
Threat investigation workflow
Incident triage owner
```

### 5. App Control for Business

Explain how application control can restrict untrusted apps and why pilot testing matters.

## Validation

You should have endpoint security control map, BitLocker plan, ASR plan, Defender integration notes, and App Control notes.

## Checkpoint Questions

1. What does BitLocker protect?
2. Why use ASR in audit mode first?
3. What does Defender for Endpoint integration enable?
4. Why are security baselines useful?

## Exam Focus

Endpoint protection questions test Intune security policies, Defender integration, BitLocker, firewall, ASR, and baselines.

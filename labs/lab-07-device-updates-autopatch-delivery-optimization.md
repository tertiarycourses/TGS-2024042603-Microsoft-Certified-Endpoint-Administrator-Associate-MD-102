# Lab 07 - Device Updates, Autopatch, Delivery Optimization

## Objectives

- Plan Windows update rings.
- Configure feature and quality update concepts.
- Explain Windows Autopatch and Hotpatch.
- Plan updates for Apple and Android devices.
- Configure Delivery Optimization concepts.

## Scenario

The organization needs predictable endpoint updates with pilot testing, reporting, and rollback planning.

## Steps

### 1. Design Update Rings

| Ring | Users | Deferral |
| --- | --- | --- |
| Pilot | IT and early adopters | Short |
| Broad | Standard users | Moderate |
| Critical | Special devices | Controlled |

### 2. Plan Windows Updates

Document:

- Update ring settings.
- Feature update policy.
- Quality update policy.
- Restart behavior.
- Deadline.
- Reporting.

### 3. Review Autopatch and Hotpatch

Explain:

- What Windows Autopatch automates.
- When Hotpatch can reduce restart impact.
- What prerequisites may apply.

### 4. Plan Non-Windows Updates

Document update policies for:

- iOS/iPadOS.
- macOS.
- Android configuration or FOTA options.

### 5. Delivery Optimization

Record:

- Download mode.
- Peer caching.
- Bandwidth control.
- Group IDs.
- Monitoring needs.

## Validation

You should have update ring design, Windows update plan, Autopatch notes, non-Windows update plan, and Delivery Optimization notes.

## Checkpoint Questions

1. Why use update rings?
2. What is the difference between feature and quality updates?
3. What does Windows Autopatch help automate?
4. Why configure Delivery Optimization?

## Exam Focus

Update management questions test rings, feature/quality updates, Autopatch, platform update policies, and monitoring.
